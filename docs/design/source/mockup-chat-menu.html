这是部署时报错的截图，帮我看下是哪个端口被占了
deploy.log — bash
15:28:01 INF build app@0.2.1 15:28:02 INF resolve deps 142 modules 15:28:04 INF starting deploy host 203.0.113.21 15:28:04 ERR listen EADDRINUSE :::54026 15:28:04 ERR at TCPListenWrap.handle 15:28:05 WRN retry 1/3 in 2s 15:28:07 ERR listen EADDRINUSE :::54026 15:28:07 ERR deploy failed (exit 1)
D

日志最后几行是关键：EADDRINUSE :::54026 说明 DSH 的 Web 端口被别的进程先占了。先看是哪个进程：

$ Bash netstat -ano | findstr :54026 ✓ 已完成 · 0.3s
D

占端口的是 PID 18808，是上一次没退干净的 DSH 进程。taskkill /PID 18808 /F 之后重新启动就行。

那这个进程会不会影响别的端口？
D

不会，它只监听了 54026 这一个端口，其他服务不受影响。
